📤 How to Share with Friends

Option 1: GitHub Pages (Recommended) ⭐

Host the game for free on GitHub and share a link!

  1. Go to your repository on GitHub.com
  2. Click Settings (top menu)
  3. Scroll to GitHub Pages section
  4. Select Deploy from a branch
  5. Choose main branch and root folder
  6. Click Save
  7. Wait 1-2 minutes, then your game will be live at:
    https://yourusername.github.io/space-runner-game
💡 Pro Tip: Share this link with friends - they can play instantly without downloading anything!

Option 2: Direct File Sharing

  1. Download the entire folder as ZIP

  3. Friends extract and open index.html

Option 3: Cloud Storage

  1. Upload files to Google Drive, Dropbox, or OneDrive

🎨 Customization (Advanced)

Change Game Speed

Edit game.js and find:

this.gameSpeed = 3; // Increase for faster game

Change Colors

Edit style.css and modify these colors:

#00d4ff /* Cyan - Main color */ #00ff00 /* Green - Player ship */ #ff6b6b /* Red - Asteroids */ #ffff00 /* Yellow - Collectibles */

Adjust Game Difficulty

In game.js, modify spawn rates:

this.spawnRate = 0.02; // Asteroid spawn rate this.collectibleRate = 0.01; // Star spawn rate this.powerUpRate = 0.003; // Power-up spawn rate
⚠️ Warning: Only edit if you know JavaScript. Backup files before making changes!

❓ Troubleshooting

Game won't open

  • Make sure you have a modern web browser (Chrome, Firefox, Safari, Edge)
  • Try opening in a different browser
  • Check that all files (index.html, style.css, game.js) are in the same folder

Controls not working

  • Make sure the game canvas is focused (click on it)
  • Try using on-screen buttons instead
  • Refresh the page and try again

High score not saving

  • Check if your browser allows local storage
  • Try clearing browser cache and refreshing
  • Make sure you're not in private/incognito mode

Game runs slowly

  • Close other browser tabs
  • Try a different browser or device
  • Update your browser to the latest version
